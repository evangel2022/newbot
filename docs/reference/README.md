# Reference Material

This directory contains **reference documentation captured during the architecture analysis of
a comparable public agent project**. It is kept for research and comparison purposes only.

These documents:

- do **not** describe newbot's structure, commands, or configuration;
- may use the reference project's names, paths, and terminology;
- are **not** normative — do not use them to implement or operate newbot.
